# Traducciones de Kosmara

Un archivo por idioma (`en.json`, `zh.json`…). Cada uno tiene:
- `t`: texto en español → traducción (frases exactas de la interfaz).
- `p`: prefijos para textos con cifras (por ejemplo «Saldo: » → «Balance: »).

Si un texto no está en un idioma, se usa el inglés; si tampoco está en inglés, se queda en español.
Para añadir o corregir una traducción basta con editar el archivo del idioma.
